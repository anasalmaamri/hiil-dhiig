# Hiil-Dhiig 🩸

Hal dhiig, hal nolol. Shabakad dhiig-bixin oo Soomaali ah: deeq-bixiyeyaal, codsiyo dhiig, WhatsApp, iyo Caawiye AI.

## Orod
Fur `index.html` browser-ka. PWA (rakibid iyo offline) waxay u baahan tahay `https://` ama `localhost`, tusaale `python3 -m http.server`.

## Faylasha
`index.html`, `manifest.webmanifest`, `sw.js`, `assets/icon.svg`, `assets/banner.svg`, `assets/photos/` (1.jpg–4.jpg sawirro dhab ah, oggolaansho la helay), `LICENSE`.

WhatsApp/Facebook ma muujiyaan banner SVG; ka beddel `assets/banner.png` oo ku dar `og:image` URL buuxa.

## GitHub Pages
Settings → Pages → Branch: `main` → `/ (root)`. Bogga wuxuu noqonayaa `https://magacaaga.github.io/hiil-dhiig/`.

## Habaynta (`CONFIG` gudaha index.html)
- `WHATSAPP`: lambarkaaga (tusaale `252612345678`), codsiyadu halkaas ayay tagayaan.
- `FORM_ENDPOINT`: URL ku keydiya diiwaangelinta (Google Apps Script, Formspree, Supabase). Haddii uu madhan yahay, xogta waxaa lagu keydiyaa browser-ka oo kaliya (demo).
- `AI_ENDPOINT`: server-kaaga yar oo ku xira model AI. **Ha geliin furaha API gudaha index.html**, qof walba ayaa arki kara.

## Waxa weli la dhisayo
1. Backend dhab ah (Supabase ama Firebase) iyo xaqiijinta lambarka SMS.
2. Liiska isbitaallada iyo xarumaha dhiigga ee la xaqiijiyay.
3. Ogeysiis (SMS/WhatsApp) marka dhiig loo baahdo.
4. Luuqad Ingiriisi ah.
5. Sawirro dhab ah oo Soomaali ah (`assets/`).

## Amniga & anshax
- Ha muujin lambarrada taleefanka dadweynaha.
- Dhiig ha iibin. Lacagta ka hel hay'ado, shirkado iyo deeqo.
- Macluumaadka caafimaad waa waxbarasho, dhakhtar ha u eegin.
